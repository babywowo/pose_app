# PoseApp 使用诊断指南

## 问题描述
用户点击"开始深蹲分析"后，面板的PHASE及以下参数值一直无变化，显示"-"符号。

## 根本原因
深蹲分析依赖于**摄像头实时检测**到的姿态数据。如果在Analysis页面点击"开始分析"，但摄像头页面没有运行或没有检测到人体，数据就无法流动。

---

## 正确使用流程

### 方法1：在摄像头页面使用（推荐）
1. 打开应用，切换到**"摄像头"**标签页
2. 确保摄像头能看到你的全身（站在距离摄像头2-3米处）
3. 等待调试面板显示：
   - `POSE` > 0（检测到人体）
   - `LMK` ≥ 20（关键点数量足够）
   - 骨骼线显示在画面上
4. 点击"开始分析"按钮（在摄像头页面底部）
5. 开始做深蹲动作：
   - 站立 → 下蹲（膝角 < 150°）→ 继续下蹲（膝角 < 100°）→ 起身（膝角 > 160°）
6. 观察调试面板的 `PHASE`、`REPS`、`L-KNEE`、`R-KNEE` 实时更新

### 方法2：在Analysis页面使用
1. 先切换到**"摄像头"**标签页，确保：
   - 摄像头已启动
   - 检测到人体（显示骨骼线）
2. 切换回**"分析"**标签页
3. 点击"开始深蹲分析"按钮
4. 观察面板数据更新（数据来自摄像头页面）

## 调试面板说明

### 诊断指标（右上角浮层）

| 指标 | 含义 | 正常值 | 异常原因 |
|------|------|--------|----------|
| CAM | 摄像头状态 | streaming | 检查摄像头权限 |
| FPS | 帧率 | > 10 | 摄像头性能问题 |
| FRAMES | 收到的帧数 | > 0 | 摄像头未启动 |
| FMT | 图像格式 | 35 | ML Kit格式问题 |
| INFER | 推理次数 | > 0 | 姿态检测未启动 |
| POSE | 检测到人体次数 | > 0 | 对准摄像头 |
| LMK | 关键点数量 | ≥ 20 | 保证全身可见 |
| ANALYZE | 分析状态 | ON/OFF | 点击"开始分析" |
| EXERCISE | 动作类型 | squat | 配置加载 |
| PHASE | 当前阶段 | standing/descending/bottom/ascending | 动作进行中 |
| REPS | 计数 | 0, 1, 2... | 完成的深蹲次数 |
| L-KNEE | 左膝角度 | 0-180° | 实时角度值 |
| R-KNEE | 右膝角度 | 0-180° | 实时角度值 |

### 诊断提示（底部）

1. **未收到摄像头帧 → 检查相机权限**
   - 检查应用是否有摄像头权限
   - 重新启动应用

2. **帧流 OK，推理无输出 → ML Kit 格式问题**
   - 摄像头帧格式不兼容（应为 YUV_420_888）
   - 检查设备兼容性

3. **推理 OK，未检测到人体 → 对准摄像头**
   - 确保全身在摄像头视野内
   - 站在距离摄像头2-3米处
   - 光线充足

4. **检测到人体但关键点少 → 保证全身可见**
   - 确保头部、肩膀、膝盖、脚踝都可见
   - 调整距离和角度

5. **骨骼检测正常 ✓**
   - 一切正常，可以开始分析

## 深蹲动作标准

### 阶段说明
- **standing（站立）**：膝角 > 160°，直立状态
- **descending（下蹲中）**：膝角 < 150°，开始下蹲
- **bottom（最低点）**：膝角 < 100°，达到深蹲底部
- **ascending（起身中）**：膝角 > 100°，从底部起身

### 计数规则
- 完成一次深蹲：standing → descending → bottom → ascending → standing
- 快速起身：standing → descending → bottom → standing（也计数）
- 下蹲中途起身：standing → descending → standing（不计数）

### 质量标准
- **达标深蹲**：最低点膝角 ≤ 90°
- **未达标**：最低点膝角 > 90°，提示"再深一点"

## 常见问题

### Q1: 为什么点击"开始分析"后没有反应？
**A**: 请先切换到"摄像头"标签页，确保：
- 摄像头已启动（CAM = streaming）
- 检测到人体（POSE > 0, LMK ≥ 20）
- 然后回到"分析"页面点击"开始深蹲分析"

### Q2: 为什么一直显示"站立"阶段？
**A**: 可能原因：
- 膝角没有低于160°（下蹲不够深）
- 检查L-KNEE和R-KNEE的实际值
- 确保全身在摄像头视野内

### Q3: 为什么计数不准确？
**A**: 可能原因：
- 动作不标准（下蹲不够深或起身不够高）
- 摄像头角度不佳（看不到完整下肢）
- 快速动作导致检测滞后

### Q4: 如何保存记录？
**A**: 在Analysis页面，当有计数（REPS > 0）时：
- 点击右上角"保存"按钮
- 记录会保存到"历史"页面

### Q5: 如何重置计数？
**A**: 在Analysis页面，点击"重置"按钮即可清零。

## 技术细节

### 数据流
```
摄像头 → CameraImage → PoseDetectorService → PoseFrame
                                              ↓
                                      AngleCalculator → FrameAngles
                                              ↓
                                     SquatAnalyzer.update() → ExerciseState
                                              ↓
                                    AnalysisScreen（显示面板）
```

### Provider关系
- `cameraStatusProvider`：摄像头状态
- `poseFrameProvider`：当前姿态帧
- `frameAnglesProvider`：当前帧角度
- `exerciseAnalyzerProvider`：当前分析器
- `exerciseStateProvider`：当前动作状态
- `isAnalyzingProvider`：是否在分析
- `debugStatsProvider`：调试统计

### 关键配置文件
- `assets/exercises/squat.exercise.yaml`：深蹲动作定义（阈值、阶段、质量规则）

## 建议的测试流程

### 快速测试
1. 启动应用，切换到摄像头页面
2. 站在摄像头前，确保全身可见
3. 等待调试面板显示"骨骼检测正常 ✓"
4. 点击"开始分析"
5. 做一个标准深蹲：
   - 慢慢下蹲（观察PHASE变为descending → bottom）
   - 慢慢起身（观察PHASE变为ascending → standing，REPS+1）
6. 切换到Analysis页面查看详细数据

### 完整测试
1. 连续做5次深蹲
2. 观察计数是否准确
3. 观察质量判断（达标/未达标）
4. 点击"保存"记录
5. 切换到"历史"页面查看保存的记录
